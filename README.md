# Chentong Wang · Personal Homepage

Personal academic homepage for Chentong Wang, built for GitHub Pages with HTML, CSS and JavaScript.

## Edit the site / 修改网站

- `index.html` contains the biography, papers, projects and education. Edit the Chinese text directly and the matching `data-en` attribute for English.
- `assets/css/custom.css` controls the layout and light/dark colors.
- `assets/img/` contains the avatar, paper figures and university seals.
- `assets/js/preferences.js` and `assets/js/theme.js` handle theme and language preferences.

Open `index.html` in a browser to preview locally. No build step is required.

在 GitHub 中打开相应文件，点击铅笔图标修改，提交后 GitHub Pages 会自动更新。

## Publishing

GitHub Pages uses the `main` branch and repository root. The site address is https://chentongwang.github.io/ once deployment completes.
